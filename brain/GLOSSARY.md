# Глоссарий

| Термин | Значение |
|---|---|
| Второй мозг | Файловая база знаний в `brain/`, которую агент читает и обновляет между сессиями. |
| Brief | Короткая сводка: `STATE.md`, последняя сессия и карта. |
| Pack | Подборка релевантных файлов и секций под формулировку задачи. |
| Search | Поиск по brain с BM25, префиксами и синонимами. |
| Area | Область знаний: один файл `areas/<тема>.md` про модуль, сервис или процесс. |
| Session | Ручной журнал работ за дату. |
| Auto journal | Черновик плагина в `sessions/auto/`; не источник истины. |
| Handoff | Краткое состояние для следующего агента. |
| Inbox | Неклассифицированные заметки до разбора. |
| Frontmatter | Блок `---` в начале Markdown с `title`, `summary`, `tags`, `updated`. |
| Lint | Проверка ссылок, размеров, frontmatter и похожих на секреты строк. |
