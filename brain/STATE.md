# Состояние

## Фокус
1. Заполнить `PROJECT.md`: каталоги, репозитории, окружение и проверенные команды.
2. Заполнить `GLOSSARY.md` терминами проекта.
3. Завести первые области знаний в `areas/` по шаблону `templates/area.md`.

## Открытые вопросы
- [ ] Какие команды запуска тестов и сборки подтверждены?
- [ ] Где лежат актуальные требования и документация?
- [ ] Какие ограничения окружения нужно учитывать агенту?

## Следующие шаги
1. Начать задачу с `py -3 brain/brain.py pack "<задача>"`.
2. При необходимости открыть `STATE.md` и только релевантные файлы.
3. В конце сессии просмотреть `sessions/auto/`, перенести выводы в `sessions/YYYY-MM-DD.md`.
4. Обновить `STATE.md`, `areas/*.md` и `DECISIONS.md`, затем выполнить `lint`.

## Handoff
Новый агент: начни с `py -3 brain/brain.py brief`, затем открой только релевантные файлы. Не читай большие документы целиком. `sessions/auto/` — черновик, не источник истины. Источник истины — код и актуальные docs.
