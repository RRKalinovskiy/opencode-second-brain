# Второй мозг

Это не история чата, а сжатая база знаний проекта. Читать по частям, не целиком.

## С чего начать
| Задача | Действие |
|---|---|
| Понять текущий фокус | [STATE.md](STATE.md) |
| Найти факт или термин | `py -3 brain/brain.py search "<термин>"` |
| Собрать контекст под задачу | `py -3 brain/brain.py pack "<задача>"` |
| Понять структуру проекта | [PROJECT.md](PROJECT.md) |
| Посмотреть автожурнал | [sessions/auto/](sessions/auto/) — черновик плагина |
| Сохранить итоги сессии | `/brain-save` или [sessions/](sessions/) |

## Карта знаний

### Области
- [areas/](areas/) — по одной области знаний на файл: структура, факты, риски, ссылки.

### Справочники
- [GLOSSARY.md](GLOSSARY.md) — термины проекта.
- [DECISIONS.md](DECISIONS.md) — принятые решения и их причины.
- [inbox.md](inbox.md) — неклассифицированные заметки.
- [playbooks/work.md](playbooks/work.md) — протокол работы с вторым мозгом.

### Журнал
- [sessions/](sessions/) — ручные журналы по датам.
- [sessions/auto/](sessions/auto/) — автоматические записи плагина `.opencode/plugins/second-brain`; черновик, требует проверки.

### Шаблоны
- [templates/session.md](templates/session.md) — журнал сессии.
- [templates/area.md](templates/area.md) — новая область знаний.
- [templates/decision.md](templates/decision.md) — новое решение.

## Правила
1. **Один факт — одно место.** Не копировать большие документы, а ссылаться на файл и раздел.
2. **Ссылка вместо копии.** В записи указывать путь и, если нужно, номер строки/раздел.
3. **Дата и статус.** У области — `updated`, у решения — дата и статус, у сессии — дата.
4. **Размер.** Файл области — до ~300 строк, сессия — до ~80 строк. Больше — разбивать.
5. **Секреты.** Пароли, токены и персональные данные не хранить.
6. **Источник истины — код и актуальные docs.** Если brain противоречит коду, прав код; brain обновить.
7. **Автожурнал — черновик.** Записи `sessions/auto/` делает плагин; проверять и переносить выводы в ручной журнал.

## Команды
```bash
py -3 brain/brain.py brief
py -3 brain/brain.py pack "задача"
py -3 brain/brain.py search "термин"
py -3 brain/brain.py note "мысль"
py -3 brain/brain.py new-session
py -3 brain/brain.py lint
py -3 brain/brain.py stats
```
